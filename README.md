# Yu-Gi-Oh AI
 yu-gi-oh playing ai<br>
 성균관대학교 기계공학과/소프트웨어학과 이상수의 소프트웨어학과 졸업 작품<br>
이 작품은 어떠한 상업적 이익이나 금전적 목적 없이, 순수히 기술의 발전과 작품성만을 위해 제작되었습니다.<br>
저는 이 작품을 통해 창작의 기쁨과 기술적 탐구를 나누고자 했습니다.<br>
따라서 이 작품은 상업적 판매나 수익 창출을 목표로 하지 않으며, 오로지 기술적 가치와 재미를 전달하는 데 중점을 두고 있습니다.

game_builded 폴더에는 빌드된 게임이 존재하여 지금까지 만들어진 unity게임의 실행파일을 실행해볼 수 있음<br><br>
rlcard 폴더에는 RL_card 환경이 존재하고, rlcard-master의 저작권 문제가 염려되어 해당 프로젝트에서 개발된 내용이 포함된 rlcard 폴더만 존재함.<br><br>
실제로 rlcard로 개발된 프로그램을 돌리려면 추가적으로 rlcard 환경을 설치할 것을 권장함<br><br>
rlcard_test.ipynb은 rlcard로 만들어진 환경을 Google Colab에서 동작 시킬 때 활용한 실행코드가 있음. <br><br>
